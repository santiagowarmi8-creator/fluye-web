# appfluye.app
Sitio público de Fluye (landing, privacidad, términos) + app web en `/app/` (build de reservas-app con `npx vite build --mode web`, que lee `.env.web`: API de producción + Firebase Auth para Google). Publicado con GitHub Pages.
Fuentes sin minificar de theme.js, welcome.js, fluye-opinion.js y styles.css: /workspace/fluye-web-src (fuera del repositorio). Los .js/.css publicados están minificados; no hay sourcemaps ni archivos de depuración.
